# 后端代码规范
## 规范来源
遵循 Python 官方 **PEP 8** 代码风格指南，参考 Google Python Style Guide 补充约定。

## 核心规范
1. 缩进：使用4个空格缩进，禁止使用Tab
2. 命名：
   - 变量、函数：蛇形命名法（snake_case），如 `add_history`
   - 类：大驼峰命名法（PascalCase），如 `CalculatorError`
   - 常量：全大写下划线分隔，如 `DATABASE_PATH`
3. 行长度：单行不超过120字符
4. 导入顺序：标准库 → 第三方库 → 本地模块，分组间空行分隔
5. 异常：使用自定义异常类区分业务错误和系统错误
6. 函数：单一职责原则，复杂函数添加功能说明注释
